# Guía de Instalación y Validación de Licencia

¡Gracias por adquirir nuestro software!

Este paquete contiene tu archivo de configuración de licencia y los scripts necesarios para ejecutar el programa de forma segura.

---

## 📋 Archivos Incluidos

- `license_config.json`: Tu archivo de licencia personalizado (Contiene tu correo registrado y tu clave de 1 uso).
- `ejecutar_cliente.py`: Script ejecutable en Python.
- `ejecutar_cliente.js`: Script ejecutable en Node.js.

---

## 🚀 Requisitos de Funcionamiento

> [!IMPORTANT]
> **Conexión Constante a Internet:**
> El software requiere **conexión constante al servidor** para verificar la validez de tu licencia mediante rotación de claves dinámicas. Si se interrumpe la conexión o la licencia es suspendida por el administrador, el programa se cerrará automáticamente.

---

## 🏃 Como Ejecutar

### Opción A: Con Python
```bash
python ejecutar_cliente.py
```

### Opción B: Con Node.js
```bash
node ejecutar_cliente.js
```
